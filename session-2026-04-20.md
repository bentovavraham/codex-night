### 7. Unified Audit Trail / Contract History

**Problem:** History tab on contract detail only showed "contract created" and "contract edited". Invoices, change orders, T&M, and expenses were invisible in the history. T&M and expenses had no log tables at all.

**Root cause:**
- `contract_logs` only written to on contract create/edit
- `invoice_logs` written to per invoice action — but history endpoint only read `contract_logs`
- `change_order_logs` written to per CO action — also not included in history
- `tm_charges` and `contract_expenses` — no log tables, no audit trail at all

**Fixed — backend:**

`routes/contracts.js` — Rewrote `GET /api/contracts/:id/history` as a UNION query:
```sql
contract_logs          -- contract created, edited, + T&M/expense events
UNION ALL
invoice_logs           -- joined via invoices.contract_id
UNION ALL
change_order_logs      -- joined via change_orders.contract_id
ORDER BY changed_at DESC
```

`routes/tmCharges.js` — Added `contract_logs` writes (using transactions) on:
- T&M added, approved, rejected, deleted

`routes/contractExpenses.js` — Added `contract_logs` writes on:
- Expense added, approved, rejected, deleted

**Fixed — frontend:**

`Contracts.js` history tab — Rewrote to display a real audit trail:
- Colored icon per event type (contract, invoice, CO, T&M, expense)
- Action label in matching color
- Dollar amount shown when relevant
- Full detail text
- Who + when on the right
- Alternating row backgrounds for readability

**Result:** Every financial event touching a contract now appears in the history tab in chronological order, newest first. The tab is a complete audit trail from contract creation through every invoice, CO, T&M charge, and expense — who did what, for how much, and when.

## Financial Model (Definitions — Confirmed)

| Term | Definition |
|---|---|
| **Contract** | Signed agreement — the base number |
| **Earmarked Amount** | Internal budget set aside including expected extras |
| **Commitment** | Contract value + approved COs only (legal obligation) |
| **Total Exposure** | Commitment + approved T&M + approved Expenses (full spend risk) |
| **Buffer** | Earmarked − Total Exposure (room left before "get more money") |
| **Cost Creep** | Total Exposure > Earmarked |
| **Contract Overrun** | Invoiced > Initial Contract Amount (previously "Getting Banged Out") |
